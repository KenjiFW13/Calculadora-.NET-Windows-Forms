## 📋 Resumo Detalhado do Projeto

Esta aplicação foi desenvolvida utilizando a linguagem **C#** com o framework **Windows Forms** no **Visual Studio 2022**. O objetivo principal foi criar uma calculadora funcional com interface gráfica intuitiva, estruturada em boas práticas de programação e separação de responsabilidades (com classes de negócios dedicadas).

### Funcionalidades Principais:
1. **Visor Inteligente:** Mostrador com alinhamento à direita para exibição de números e resultados com suporte a tipos de ponto flutuante (`double`/`float`).
2. **Operações Aritméticas Básicas:** Execução precisa de Adição ($+$), Subtração ($-$), Multiplicação ($\times$) e Divisão ($/$), incluindo tratamento de erros para divisão por zero.
3. **Funções Semi-Científicas:** 
   * **Raiz Quadrada ($\sqrt{x}$):** Cálculo imediato da raiz de um número com validação de domínio para números reais.
   * **Potenciação ($x^y$):** Elevação de uma base a um expoente personalizado.
4. **Suporte a Decimais:** Inserção de números decimais utilizando vírgula (`,`).
5. **Controle e Memória:** Botões de igual ($=$) para computar os resultados e botão de limpeza ($C$) para resetar o estado da calculadora e a memória de variáveis.
6. **Tela "Sobre":** Um formulário secundário acessível via interface que exibe as informações detalhadas do grupo, a turma e a proposta do trabalho.

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o **Visual Studio 2022** instalado com o pacote de desenvolvimento para Desktop em .NET.
2. Clone este repositório ou baixe o arquivo `.zip` contendo a solução (`.sln`).
3. Abra a solução no Visual Studio.
4. Defina o projeto da calculadora como o **StartUp Project**.
5. Pressione `F5` ou clique em **Start** para compilar e executar a aplicação.
